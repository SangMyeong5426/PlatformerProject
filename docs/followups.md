# 나중에 확인할 것

**결함 목록이 아니다.** 지금 잘못 돌고 있는 것은 고치거나 work log 에 적는다. 여기 있는 것은
**지금은 판단할 근거가 없거나 확인할 수단이 없어서 미뤄 둔 것**이다.

미뤘다는 사실을 어딘가에 적어 두지 않으면 조건이 갖춰진 뒤에도 아무도 다시 오지 않는다.

## 규칙

- 항목을 지울 때는 **무엇을 확인했고 결론이 무엇이었는지**를 관련 문서에 먼저 남기고 지운다.
  그냥 지우면 확인한 것인지 잊은 것인지 구분되지 않는다.
- **조건이 갖춰졌는데 아직 안 한 것**과 **조건이 아직인 것**을 섞지 않는다. `언제` 칸이 그
  구분이다.
- 근거가 ADR 이나 work log 에 있으면 그것을 가리키고 여기에 다시 적지 않는다.
